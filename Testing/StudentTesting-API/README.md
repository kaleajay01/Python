# Student Testing API

A simple API to manage student data.

## CRUD Operations

- Create Policy
- Get All Policies
- Get Policy By ID
- Update Policy
- Delete Policy

## Technologies

- Python
- FastAPI
- Pydantic
- Uvicorn
- Pytest

## Run Project

uvicorn app.main:app --reload
